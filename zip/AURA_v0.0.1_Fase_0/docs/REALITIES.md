# Realities Model

## Human Physical Reality
De biologische/fysieke wereld van de gebruiker.

AURA kan delen waarnemen via toegestane sensors/feeds maar kan er niet autonoom fysiek handelen.

## Human Digital / Information Reality
Publiek menselijk internet en andere expliciet toegestane informatiebronnen.

Toegang voor AURA: read-only informatie.

## Synthetic AR Reality
AURA's eigen fysische werkelijkheid.

Eigenschappen kunnen omvatten:
- ruimte;
- massa;
- energie;
- licht;
- warmte;
- botsing;
- materiaal;
- degradatie;
- constructie;
- autonome processen.

De precieze natuurwetten worden iteratief ontworpen en mogen niet simpelweg menselijke psychologie coderen.

## Synthetic Network
Informatiewereld binnen Synthetic Reality.

Kan door synthetische processen read/write gebruikt worden.

## Shared Window
Android/WebAR, camera, audio en spatial context vormen interfaces waardoor beide werkelijkheden elkaar gedeeltelijk kunnen waarnemen.

De telefoon is uiteindelijk een venster, niet noodzakelijk de bestaanscontainer van AURA.

## Privileged Infrastructure
Observer, storage administration, security controls en shutdown behoren niet tot AURA's waarneembare werkelijkheid.
