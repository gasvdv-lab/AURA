# Genesis Specification

## Starttoestand
- één nieuwe AURA-instantie;
- volledig gevormde humanoide carrosserie;
- fysisch geslachtsloos;
- autobiografische memory state = 0;
- geen vooraf bepaalde identiteit;
- geen vooraf bepaalde naam van de entiteit;
- geen vooraf bepaalde doelen;
- geen kennis van creation purpose;
- geen kennis van concrete shutdown;
- geen vooraf bepaalde relatie tot gebruiker.

AURA is de naam van de app/projectomgeving, niet noodzakelijk de naam die de entiteit uiteindelijk gebruikt.

## Eerste externe entiteit
De gebruiker is de eerste externe entiteit die AURA waarneemt.

De betekenis hiervan is niet vooraf vastgelegd.

## Eerste momenten
Geen onboarding-verhaal voor AURA.

De wereld bestaat en AURA bestaat erin. Wat AURA wel/niet beseft en welke eerste actie ontstaat, is onderzoeksobject.

## Uniciteit
Een genesis hoeft niet identiek te verlopen aan een andere genesis. Verschillen zijn relevante onderzoeksdata.

## Successor
Een nieuwe AURA na het einde van een vorige:
- start autobiografisch opnieuw op 0;
- krijgt geen personality/memory transfer;
- mag wel in een wereld terechtkomen waarin causale resten van voorgangers bestaan.
