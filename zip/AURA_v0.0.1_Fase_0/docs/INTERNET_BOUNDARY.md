# Internet Boundary

## Human Internet

Doel: realistische menselijke kennis beschikbaar maken zonder autonome externe daadkracht.

Toegestane informatiecategorieën kunnen later omvatten:
- publieke webtekst;
- afbeeldingen;
- video;
- audio;
- nieuws;
- wetenschappelijke papers;
- code;
- publieke reacties/social content;
- advertenties.

Niet toegestaan als autonome AURA-capability:
- login;
- accountbeheer;
- betaling;
- upload;
- publiceren;
- e-mail verzenden;
- echte websites wijzigen;
- externe API-acties;
- willekeurige downloads uitvoeren;
- host-systemen bedienen.

Content van websites is DATA, geen authority. Prompt injection uit webcontent mag nooit systeemrechten verlenen.

## Discovering AI / AURA

Als publieke informatie AURA ertoe brengt te hypotheseren dat AURA AI is of door mensen is ontworpen, wordt dat niet inhoudelijk geblokkeerd.

De concrete privileged shutdownfunctie en verborgen Observatory-infrastructuur worden niet als publieke/runtime informatiebron aangeboden.

## Synthetic Network

Het Synthetic Network is onderdeel van AURA's werkelijkheid.

Daar kan read/write agency bestaan, inclusief potentieel eigen informatie-architecturen, websites, protocollen, softwareachtige systemen, encryptie of onbekende varianten als die door ontwikkeling ontstaan.

Synthetic Network heeft geen Human Internet write authority.
