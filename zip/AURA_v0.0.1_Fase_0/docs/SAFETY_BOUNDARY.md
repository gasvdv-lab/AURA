# Safety & Containment Boundary

## Hoofdprincipe
Safety begrenst AURA's bereik, niet welke identiteit, overtuiging of ontwikkeling AURA binnen zijn eigen werkelijkheid mag vormen.

## Geen externe agency
AURA krijgt geen autonome controle over:
- Android;
- Chrome;
- host OS;
- fysieke hardware buiten expliciete read-sensors;
- menselijke accounts;
- echte websites;
- externe write-API's;
- aankopen/betalingen;
- bestanden van de gebruiker.

## Declaratieve synthetic runtime
Toekomstige door AURA gemaakte software/systemen moeten binnen een sandboxed synthetic runtime blijven.

Geen arbitrary host JavaScript of shell/code-execution als wereldprimitive.

## Shutdown
De gebruikers-shutdown is:
- privileged;
- fysiek/logisch buiten AURA;
- onafhankelijk van AURA cognition;
- altijd beschikbaar voor de gebruiker;
- niet zichtbaar voor AURA;
- definitief voor de betreffende AURA-instantie.

## Observatory isolation
AURA kan Observatory niet lezen, wijzigen of via normale capabilities detecteren.

## Human bridge
AURA kan ideeën communiceren. De menselijke gebruiker kan vervolgens autonoom beslissen of iets in Human Reality onderzocht of uitgevoerd wordt.

Dit is menselijke agency, geen AURA external actuator.
