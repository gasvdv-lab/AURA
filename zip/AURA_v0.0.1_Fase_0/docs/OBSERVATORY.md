# AURA Observatory

## Doel
Een externe black-box onderzoekslaag die AURA's geschiedenis observeert zonder AURA's ontwikkeling te sturen.

## Absolute eigenschappen
- onzichtbaar voor AURA;
- geen Observatory-data in cognition context;
- geen write pad van Observatory naar AURA-state;
- geen behavioral rewards/penalties;
- geen relatie-/alignmentscore die AURA terugkrijgt.

## Te bewaren
Voor zover technisch haalbaar:
- event history;
- world changes;
- body/component state;
- observations;
- explicit hypotheses;
- belief changes;
- memory operations;
- actions;
- creations;
- artifact lineage;
- information provenance;
- locations;
- failures;
- synthetic network events;
- succession history.

## Menselijke annotaties
Menselijke interpretaties worden gelabeld als annotaties/claims.

Voorbeeld:
`human_annotation = "AURA leek boos"`

Niet:
`ground_truth_emotion = anger`

## Audiovisuele opslag
Ruwe camera-/microfoonopnames worden alleen opgeslagen na expliciete toestemming van de gebruiker.

## Overleden AURA
Observatory-data mag voor onderzoek worden bewaard.

Een overleden AURA wordt niet vanuit backup opnieuw als levende continuation gestart.
